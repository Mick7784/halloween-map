# V0.8.6 — compte et Frissons adaptés

Base : main `93d6bf0`, release V0.8.5 déjà publiée. La V0.8.6 conserve ce tag existant.

## Changements

- La rubrique des années utilise les styles partagés `account-row`, son icône calendrier, son sous-titre et son chevron. Un `details` natif se déplie sans navigation, avec clavier et focus visible.
- La source reste `/api/history` : années seules de l’utilisateur connecté, issues des participations validées en saison réelle. Les années identiques sont dédoublonnées pour l’affichage. Aucun changement du déclencheur SQL, de la rétention de cinq ans, de la purge saisonnière ou de l’effacement avec le compte.
- Le libellé « Frissons adaptés », les deux masques au trait et l’explication âge/sensibilité sont utilisés dans les fiches, listes et formulaires. Les consultations du compte et du back-office emploient le même libellé.
- Les niveaux fixes, leur désactivation dans le formulaire lorsque l’adaptation est active, les filtres et les règles serveur sont conservés. Aucune migration.
- Version canonique et cache statique PWA synchronisés en V0.8.6.

## Validation locale

- Lint, TypeScript et build de production réussis.
- 217 tests unitaires réussis, dont l’historique validé, sa conservation après purge et sa suppression avec le compte.
- 17 tests navigateur du compte réussis, dont les nouveaux contrôles à 390 et 1440 px : mêmes styles que les rubriques voisines, clic/clavier, absence de navigation, années uniques et état vide.
- Captures mobile et desktop inspectées ; thème Halloween conservé. Données de compte et années fictives dans les fixtures uniquement.

## Publication

La CI habituelle doit réussir avant fusion : migrations PostgreSQL exécutées deux fois, lint, unitaires, build, E2E complets et stack Docker avec contrôle `/api/health` et VERSION. Sur main, elle publie `ghcr.io/mick7784/halloween-map:V0.8.6`, `latest`, le tag et la GitHub Release Beta.

Le pull Dockhand appartient au propriétaire. La publication de l’image ne prouve pas que le serveur de production l’a déjà téléchargée ; aucun accès Dockhand ou URL de production n’est fourni dans le dépôt.
