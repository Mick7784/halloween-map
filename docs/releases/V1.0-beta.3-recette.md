# Halloween Map — recette V1.0-beta.3 (22 octobre 2026)

## Périmètre

Cette bêta prolonge la V1.0-beta.2, dont l'éditeur à pictogrammes classiques a reçu un premier accord visuel utilisateur. Le seul changement de présentation ciblé ici est le **wordmark de la sidebar** : PNG transparent issu du WebP officiel conservé, avec ombre discrète pour rester lisible en thème clair. Il n'y a **aucune promesse de validation fonctionnelle complète** du fait de cet accord.
