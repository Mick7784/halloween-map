# Validation V0.8.2 — carte, collecte, participation et éditeur

Branche : `work/v08-ui-collection-editor`, base `a705587a8b31068d9b890ae7f5c3b6fd62566820` (V0.8.1). Le dépôt local était propre à l’ouverture ; aucun travail local antérieur, fichier synchronisé sous `sources/`, service Dockhand ou donnée de production modifié.

## Changements

- Consultation : accès explicite « Les maisons à découvrir », pins minimaux orange et halo sur la plus proche admissible quand le GPS est fiable. Préparation et collecte : uniquement la sélection affichée ; la carte n’ajoute aucune source/couche de tracé, instruction ou guidage. Ordre libre et tri de proximité restent distincts.
- Collecte : liste extensible, ajout immédiat sans doublon, candidats disponibles même hors filtres initiaux, nom/distance GPS à vol d’oiseau/activités/frayeur/adaptabilité. Sans GPS fiable, la distance actuelle est indisponible et le classement utilise le point retenu ; cela ne constitue pas une navigation. Disponibilité recontrôlée côté API après ajout. Progression, chrono et mesure GPS observée dans le panneau bas ; filtrage de dérive et gestion des interruptions existants conservés, aucune série de positions persistée.
- Formulaire : ville et code postal administrés, validation API correspondante, date au 31 octobre de la saison, heures vides et obligatoires, fin possible le lendemain. Les dates sentinelles TEST ne sont pas affichées. Les localisations historiques inchangées peuvent être conservées après changement de configuration ; une modification structurée du lieu repasse les validations. L’exception d’administration pour les anciennes adresses en texte libre est conservée.
- Icônes partagées Candy/Sparkles/Drama et libellés uniques. Logo ManorMark conservé, nom Halloween Map visible, en-têtes responsive et commandes BO alignées.
- Tiptap commun aux contenus, légaux, modèles et campagnes ; même format de stockage existant, sans migration. Seuls les styles réellement rendus sont disponibles : titres, gras/italique combinés, listes plates et liens HTTPS/mailto/internes sûrs ; texte collé sans HTML, undo/redo. Les modèles sont non éditables pendant leur chargement pour éviter l’écrasement d’une saisie précoce. Aucun support d’images promis.

## Vérifications locales

- Installation propre par `npm ci`, lint/TypeScript, tests unitaires et build de production.
- 207 tests unitaires : adresses et compatibilité historique, saisons, permissions/reconfirmation, distance GPS et interruptions, ajout hors filtres, rendu sûr et dates TEST.
- 109 scénarios Chromium validés avec PostgreSQL 17.10 isolé : 107 réussis au passage complet, puis les deux tests Tiptap rejoués avec succès après correction de leur attente de mise en forme conservée. Les parcours navigateur → API → DB couvrent créations, rejets d’adresse, reconfirmations, permissions, modération, saisons, sauvegarde/rechargement de l’éditeur et prévisualisation email. Les tests de carte contrôlent sélection, retrait/ajout, halo, expiration GPS, reprise et absence de chevauchements mobile. La CI PR rejoue toute la suite en un passage.
- Migrations existantes 001–010 rejouées deux fois sur cette base ; aucune migration nouvelle. SMTP TLS et STARTTLS réels contre des fixtures locales, MIME des six modèles, outbox et absence de doublons. Les fournisseurs d’adresse et certains scénarios UI utilisent des fixtures ; ils ne prouvent pas la disponibilité d’un fournisseur externe.
- Contrôles responsive mobiles et desktop, thèmes et absence de débordement ; captures dans les artefacts navigateur.
- Audit `npm audit --omit=dev` : aucune vulnérabilité applicative signalée le 11 octobre 2026.
