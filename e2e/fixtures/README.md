# Fixtures SMTP locales

Le certificat et sa clé privée sont publics et exclusivement réservés aux serveurs de test locaux (127.0.0.1/localhost). Ne pas les utiliser pour une instance réelle. Playwright les approuve via NODE_EXTRA_CA_CERTS ; la vérification TLS reste activée. Les destinataires sont limités à @example.invalid. Ces fichiers ne sont pas copiés dans l’image applicative finale.
