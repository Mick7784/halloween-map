# Revue V0.9.2

Ouvrir `index.html` pour comparer les surfaces mobile et desktop. Les captures proviennent de Playwright, avec des comptes et maisons fictifs. Les panneaux cartographiques utilisent des fixtures sans fond de carte de production. Les anneaux ambre sont les états de focus clavier volontairement vérifiés.

La nouvelle icône est un SVG natif, dérivé du symbole citrouille existant et associé à un repère de carte violet. Les PNG d’installation sont générés par `scripts/pwa-assets.mjs`, avec fond opaque et zone sûre pour les variantes maskable. Aucune nouvelle génération d’image du village.

L’accueil partagé et le vrai logo DK restent ceux de la V0.9.1 acceptée. Cette version harmonise les surfaces de l’application sans modifier les règles métier. Aucun merge, publication ou remplacement de latest.
